Rename the app to Style Assist and build the Killer Feature: Outfit Timeline Engine

IMPORTANT:
Do not redesign the whole app randomly
Do not change the design system unless required
Do not remove existing wardrobe, recommendation, product, or save flows
Build this as the central app experience

GOAL:
Create a premium outfit planning system where users can plan outfits 1 week, 2 weeks, or 4 weeks ahead using:
1. wardrobe items they already own
2. incoming delivery items
3. upcoming events
4. AI-style outfit recommendations
5. save-to-timeline planning

CORE LOOP:
wardrobe → recommendation → product/incoming item → save → timeline

FEATURE NAME:
Outfit Timeline Engine

MAIN SCREEN:
Create a screen called Timeline or Plan Ahead

The user must be able to:
- view outfits by day
- switch between 1 week, 2 week, and 4 week planning
- tap an empty day to generate outfit suggestions
- save an outfit to a future date
- include incoming delivery items only if they arrive before or on that date
- drag an outfit from one day to another
- remove an outfit from a day
- duplicate an outfit to another day

DATA MODELS:
Create these data structures if they do not already exist:

wardrobe_items:
- id
- name
- category: top, bottom, dress, shoes, outerwear, accessory
- image
- color
- style_tags
- season_tags
- owned: true

incoming_items:
- id
- name
- category
- image
- color
- style_tags
- delivery_date
- store_name
- owned: false

events:
- id
- title
- date
- event_type: wedding, birthday, dinner, work, casual, party, holiday, travel, other
- dress_code
- notes

outfits:
- id
- name
- item_ids
- date
- event_id optional
- confidence: high, safe, experimental
- tags

OUTFIT GENERATION LOGIC:
When generating outfits for a selected date:

1. Include all wardrobe_items
2. Include incoming_items only when:
   incoming_item.delivery_date <= selected_date

3. Generate outfit combinations using:
- one top OR one dress
- one bottom if no dress
- one pair of shoes
- optional outerwear
- optional accessories

4. Match to event type when possible:
- wedding: dressy, elegant, formal
- birthday: fun, stylish, bold
- dinner: smart casual, elegant
- work: clean, professional
- casual: relaxed, simple
- party: bold, expressive
- holiday: seasonal, themed
- travel: comfortable, practical

5. Assign confidence:
- high = strong event match + complete outfit
- safe = complete outfit but neutral
- experimental = unusual mix, bold colour, or less certain match

Add a main CTA button:
“Plan My Month”

- respect incoming item delivery dates
- respect event dates
- fill empty timeline days only
- do not overwrite existing saved outfits unless user confirms
- show a calm planning animation before filling the timeline
